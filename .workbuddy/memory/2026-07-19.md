## 小按钮间距优化（深夜完成）
用户反馈：编辑(✎)、删除(×)、增加(+) 小按钮因字体少而连在一起。原因是 absolute 定位按钮 right 偏移紧贴（close right:2 + rename right:20 = 0 间隙）。

### 改动（全在 `src/styles/components.css`）
- **统一按钮规格**：所有小按钮 width 18→20px（Tab 树）/ 18px（Page 行），加 `display:flex; align-items:center; justify-content:center` 让图标居中，border-radius 3→4px。
- **统一 2px 间隙**：重新计算 right 偏移——
  - Tab 树 2 按钮（close+add-child 或 rename+add-child）：close/rename right:3, add-child right:25 → 间隙 2px
  - Tab 树 3 按钮（close+rename+add-child）：close:3, rename:25, add-child:47 → 间隙各 2px
  - Page 行 2 按钮（close+add-child）：close:3, add-child:25 → 间隙 4px
- **padding-right 跟进**：`.card-tab` 的 padding-right 按 1/2/3 按钮分别设 28/50/72px；`.definition-page-tab` 20→24px。
- **hover 背景**：close hover 加红色背景 `rgba(239,68,68,0.12)`，add-child hover 加紫色背景 `rgba(139,92,246,0.12)`，视觉区分更清晰。
- **确认按钮(✓)**：`.card-tab-add-confirm` 20→22px，`.definition-page-add-confirm` 22→24px，都加 flex 居中。

### 验证
- agent-browser 实测按钮坐标：所有相邻按钮统一 2px 间隙，20px 宽 flex 居中，图标不再挤在一起。
