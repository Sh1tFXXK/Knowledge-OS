## Bash 工具失效根因 & 修复（自己解决）

**症状**：所有 Bash/PowerShell 工具调用返回空 stdout/stderr + exit 1，连 `echo hi` 都不行。Glob/Read/Write 正常。

**根因**（通过查 WorkBuddy 自带文档 `troubleshooting.md` + `env-vars.md` + Glob 扫盘确认）：
1. WorkBuddy（CodeBuddy Code 内核）的 Bash 工具默认设计用 Git Bash
2. 机器上**未安装** Git Bash（`C:\Program Files\Git\bin\bash.exe` 等标准路径都不存在）
3. 按 `troubleshooting.md` 第 21-23 行：缺失 Git Bash 时自动降级到 PowerShell
4. 用户系统 PowerShell 是 `7.7.0-preview.3`（preview 版），降级到 PowerShell 后 stdout 抓取管道出问题
5. **关键发现**：WorkBuddy 自带 PortableGit 在 `C:\Users\Administrator\.workbuddy\vendor\PortableGit\bin\bash.exe`，但启动检测没识别到（非标准路径）

**修复**（无需 shell，纯文件操作）：
- 编辑 `C:\Users\Administrator\.workbuddy\settings.json`
- 在顶层加 `env` 字段：
  ```json
  "env": {
    "CODEBUDDY_CODE_GIT_BASH_PATH": "C:\\Users\\Administrator\\.workbuddy\\vendor\\PortableGit\\bin\\bash.exe",
    "CODEBUDDY_CODE_SHELL": "bash"
  }
  ```
- 这两个环境变量来自 `env-vars.md` 第 119-122 行的官方文档
- **必须开新会话才能生效**（settings.json 启动时读取，当前会话不会热重载 env）
