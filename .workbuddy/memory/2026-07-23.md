# 2026-07-23 工作日志

## 维基百科导入功能（scripts/import-wikipedia.mjs）

用户需求：制作「提取维基百科链接 → 整理成文档 → 导入项目」的功能。

### 决策（经用户确认）
- 形态：CLI 脚本（契合项目 scripts/*.mjs 模式）
- 拆分粒度：按维基文章自身章节结构（== / ===）映射成节点树
- 导入位置：每次必须 `--parent=<nodeRef>` 指定挂载父节点

### 实现
新增 `scripts/import-wikipedia.mjs`（自包含、无依赖、ES module），流程：
1. 解析维基 URL → 语言 + 标题
2. 调 Wikipedia Action API（action=parse, prop=wikitext, redirects=1）抓 wikitext
3. 按 `==`/`===` 标题行切分章节建嵌套树
4. wikitext→Markdown 转换器（标题/粗斜体/链接/列表/模板剥离/去 ref 表格媒体）
5. 按文档结构生成节点：文章标题为根（挂 --parent 下），H2 子节点，H3 孙节点；黑名单章节（参见/外部链接/参考文献，中英文+繁简）不建节点
6. 幂等写入 node-pool.json / tree-data.json + 生成 docs/notes/wiki-<lang>_<slug>.md

节点 id 稳定：`k_wiki_<lang>_<slug>[_sN]`，重复导入更新不翻倍，子树每次重建不残留。

### 前端生效链路（已确认）
- vite.config.js 的 `dataFileApi()` middleware 提供 `/api/data?file=xxx` 读写 data/*.json
- App.tsx mount 时 `useEffect→initialize()`→`loadCompleteStateFromFiles()` 从文件加载
- 所以导入后启动 `npm run dev` 即在 UI 生效，无需改前端
