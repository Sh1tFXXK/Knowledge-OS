# Redis实战

本书是《Redis in Action》的中文翻译版，深入浅出地介绍了 Redis 的实际用法，通过大量示例展示如何使用 Redis 构建 Web 应用、支持程序、应用程序组件、搜索应用以及简单的社交网站，并涵盖数据安全、性能保障、降低内存占用、扩展 Redis 以及 Lua 脚本编程等进阶主题。本书由 Redis 社区知名贡献者黄健宏（huangz）翻译，示例代码使用 Python 编写。

作者：Josiah L. Carlson 著 / 黄健宏 译
